## 🚀 How to use

1. Put your birthday music in the root folder and name it exactly `birthday.mp3`.
2. Put your funny video in the root folder and name it exactly `happy.mp4`.
3. Put your ten photos inside `photos/` and name them `rm1.jpg` through `rm10.jpg`.
4. Open `index.html` locally or upload the whole folder to GitHub Pages.
5. On GitHub:
   - Open repository **Settings**
   - Select **Pages**
   - Choose the `main` branch and `/root`
   - Save and open the generated website link

## ⚠️ Browser notes

- Browsers often block autoplay. Tap **Enter Your Universe** or the sound button to start music.
- File names are case-sensitive on GitHub Pages. Keep `happy.mp4` exactly as written.
- Use compressed photos and video for faster mobile loading.
